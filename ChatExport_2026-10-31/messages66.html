Если грубо, то для авторегрессионного декодинга (когда модель генерит токен за токеном) — каждый токен требует ~2N FLOPs, где N — число параметров. Это потому что inference memory-bandwidth bound: нужно прочитать все веса из памяти для каждого токена.

Прикидка:
• 70B модель ≈ 140 GFLOPs на токен
• H100 даёт ~50 TFLOPS в memory-bound режиме → ~100–300 tok/s на GPU
• Аренда H100 ≈ $2–3/час
• Итого: грубо $5–15 за 1M выходных токенов для 70B

Дальше умножаем:
• reasoning-модель (o1, Claude с thinking) жжёт 5–20k токенов на запрос
• тяжёлый пользователь делает 100+ таких запросов в день
• → $200 подписка не покрывает даже одного такого юзера

Prefill (обработка контекста) добавляет ещё ~2·N·L FLOPs, где L — длина контекста. Для длинных диалогов это тоже ощутимо.

Так что оценки в посте по порядку величины похожи на правду — это задокументированные подсчёты по публичным данным о железе и бенчмаркам.

Это reasoning-модели, которые перед тем как дать ответ, "думают" вслух — генерируют цепочку рассуждений (chain-of-thought), и только потом выдают финальный ответ.

o1 / o3 — линейка OpenAI. o1-preview вышла в сентябре 2024, потом o1, o1 pro, o3, o3-mini, o4-mini. Они тратят кучу токенов на внутренние размышления, иногда десятки тысяч, прежде чем что-то ответить. Стоимость подписки ChatGPT Pro ($200/мес) во многом привязана к доступу к тяжёлым рассуждающим моделям без лимитов.

Claude с extended thinking — аналог у Anthropic, включил thinking бюджет. Тоже жжёт тысячи токенов на внутренний monologue.

Почему это важно для экономики подписки:

Обычный чат-запрос (написать письмо, перевести, объяснить концепцию) — это 200–500 токенов ответа. Дёшево.

Reasoning-запрос (математика, код с отладкой, сложный анализ) — 5к–20к токенов внутренней болтовни + 1к–2к финального ответа. В 10–30 раз дороже по вычислениям.

Так что когда подписчик платит $200 и может гонять o3 сколько влезет — Anthropic и OpenAI буквально доплачивают за него из кармана инвесторов. Отсюда и колоссальные убытки на инфре.
