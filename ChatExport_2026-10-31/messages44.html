Property Wrappers в SwiftUI — это специальные аннотации, которые управляют состоянием и данными.

@State — для локального состояния в View:
@State private var isOn = false


@Binding — двусторонняя привязка к родительскому значению:
@Binding var isOn: Bool


@Published — для ObservableObject:
class Model: ObservableObject {
    @Published var count = 0
}


@ObservedObject — подписка на внешний ObservableObject:
@ObservedObject var viewModel: MyViewModel


@StateObject — создание и владение ObservableObject (только в SwiftUI 14+):
@StateObject var viewModel = MyViewModel()


@Environment — чтение значений из окружения:
@Environment(\.colorScheme) var colorScheme
@EnvironmentObject var userSettings: Settings


@EnvironmentObject — внедрение общего объекта через окружение

@FetchRequest — для Core Data (если используешь)

@SceneStorage / @AppStorage — персистентность между запусками

Главное отличие: @StateObject создаёт объект один раз, @ObservedObject получает готовый.

DDoS (Distributed Denial of Service) — это атака типа "отказ в обслуживании".

Суть: злоумышленник перегружает сервер или сеть огромным количеством запросов со множества компьютеров (ботнет), из-за чего сервер не справляется и перестаёт работать для обычных пользователей.

В отличие от DoS — атака распределённая, с тысяч заражённых устройств, поэтому сложнее остановить.

Типичные последствия: сайт недоступен, сервис лежит, бизнес теряет деньги.

Вот основные порты, которые чаще всего блокируют для безопасности:

Удалённый доступ (блокировать снаружи)
• 22 — SSH
• 23 — Telnet (устарел, небезопасен)
• 3389 — RDP (Windows)
• 5900 — VNC

Файловые/ftp-сервисы
• 20/21 — FTP
• 69 — TFTP
• 139, 445 — SMB (Windows file sharing)
• 2049 — NFS

Базы данных (не наружу)
• 3306 — MySQL/MariaDB
• 5432 — PostgreSQL
• 27017 — MongoDB
• 6379 — Redis
• 11211 — Memcached

Почта
• 25, 465, 587 — SMTP
• 110 — POP3
• 143, 993 — IMAP

Веб
• 80, 443 — HTTP/HTTPS (обычно открыты)
• 8080, 8443 — альтернативные веб-порты

Прочее опасное
• 23 — Telnet
• 161 — SNMP
• 123 — NTP (можно оставить)
• 53 — DNS (можно оставить)

Если сервер публичный — обычно оставляют только 80/443 (веб) и 22 (SSH с ключом или Fail2Ban). Остальное — блокировать.
