Ключевые последствия Compose-first
1. View-библиотеки уходят на maintenance mode:
• CardView, ConstraintLayout, RecyclerView — только критические багфиксы
• Новые фичи не добавляются

2. Инструментарий и документация:
• Android Studio теперь оптимизирована под Compose
• Все туториалы, примеры — сначала Compose
• Новым разработчикам проще начать

3. Производительность догнала Views:
• К декабрю 2025 Compose достиг паритета по перформансу
• Раньше это был аргумент против, теперь нет

4. API стабилизировались:
• Многие экспериментальные API перешли в стабильный статус в 2025 году
• Можно использовать в продакшене без опасений



Что делать разработчикам
Ситуация                | Рекомендация                                   
------------------------+------------------------------------------------
**Новый проект**        | Сразу Compose — никаких причин использовать XML
**Существующий проект** | Постепенная миграция, новые фичи на Compose    
**Команда без опыта**   | Инвестировать в обучение — это неизбежно



Бонус: Compose постепенно забирает не только UI
Google двигает Compose за пределы экранов:
